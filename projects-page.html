Rapid Food MS

Java · Spring Boot · MySQL · Kafka

O Rapid Food MS é uma api REST desenvolvida em Java com Spring, a aplicação gerencia usuários, vendedores, produtos, pedidos e pagamentos. A arquitetura inicial era um projeto monorepo, refatorado agora para microserviços, a comunicação entre serviços ocorre de duas formas: sincrona usando OpenFeign, e assincrona através de eventos com Kafka.

Rapid Food UI

React · TypeScript · React Query · Tailwind · Shadcn/Ui

O Rapid Food UI é uma aplicação frontend, desenvolvida em React com Vite, responsável pela interface e pela interação com a API backend. A aplicação permite a realização de pedidos, visualização de restaurantes e seus produtos, cadastro de usuários consumidores e vendedores, gerenciamento de produtos na área admin.

Votação Fullstack

Java · Spring Boot · React · TypeScript · MySQL

O Desafio Votação Fullstack é uma aplicação fullstack desenvolvida com Java, Spring Boot, React e TypeScript, componentes ShadCn Ui e estilização com Tailwind CSS. Esse projeto é a solução de um desafio proposto pela equipe de desenvolvimento da unidade AR. E permite a abertura de pautas, sessões de votação e apuração dos votos, com persistência em um banco de dados MySQL.

Projeto Hotel Manager Fullstack

Java · Spring Boot · React · TypeScript · MySQL

Esse projeto resolve um problema que eu mesmo tive por muitos anos trabalhando como recepcionista de hotel, que é a dificuldade de gerenciar reservas, check-in e check-out de hóspedes. O sistema possui também acompanhamento histórico de hospedagens e de métricas de ocupação e financeiras na área administrativa, com suporte a múltiplos usuários e permissões de acesso baseadas em roles. Desenvolvido em Java, Spring Boot, React e TypeScript. O projeto está em constante evolução, recebendo novas funcionalidades e melhorias nas existentes.
