Rapid Food MS

Java · Spring Boot · MySQL · Kafka

O Rapid Food MS é uma api REST desenvolvida em Java com Spring, a aplicação gerencia usuários, vendedores, produtos, pedidos e pagamentos. A arquiterura inicial era um projeto monorepo, refatorado agora para microserviços, a comunicação entre serviços ocorre de duas formas: sincrona usando OpenFeign, e assincrona através de eventos com Kafka.

Rapid Food UI

React · TypeScript · React Query · Tailwind · Shadcn/Ui

O Rapid Food UI é uma aplicação frontend, desenvolvida em React com Vite, responsável pela interface e pela interação com a API backend. A aplicação permite a realização de pedidos, visualização de restaurantes e seus produtos, cadastro de usuários consumidores e vendedores, gerenciamento de produtos na area admin.
